## 💼 Featured Work

### 🏗️ Construction Documentation System

A construction-site documentation system for managing inspection tracking, WIR/KKF documentation, T-Wall progress, test records, calibration tracking, scanned PDFs, and digital workflow processes.

**Tech:** C# .NET, ASP.NET Core Web API, SQL Server, WinForms, Web Client, Excel/PDF automation

**Key Features:**

* Inspection tracking
* WIR/KKF workflow support
* T-Wall progress tracking
* Test and calibration records
* Scanned PDF management
* Digital signing workflow
* Desktop and web client architecture

---

### 📦 Warehouse Management System

A warehouse management system for stock operations, purchase requests, receipts, product management, departments, users, categories, units, and inventory workflows.

**Tech:** C# .NET, ASP.NET Core Web API, SQL Server, WinForms, HTML, CSS, JavaScript

**Key Features:**

* Secure login and dashboard
* Product and master-data management
* Stock-in and stock-out tracking
* Purchase request workflow
* Receipt history
* On-hand stock reports
* Backend validation for stock availability

---

### 🧪 Concrete Test Report Automation

A reporting automation tool that reads concrete test PDF/WXT reports, extracts LAB numbers, dates, concrete classes, cube weights, kN/MPa values, and supports Excel/PDF report workflows.

**Tech:** JavaScript, PDF parsing, WXT reverse engineering, Excel automation, PDF generation
